# CASAS dataset source

The dissertation uses **CASAS Smart Home dataset - scripted activities, with and without activity errors**, released on Zenodo by Diane Cook in 2025.

- Zenodo record: https://zenodo.org/records/15712834
- DOI: `10.5281/zenodo.15712834`
- Required downloads: `adl_noerror.zip` and `adl_error.zip`
- Dataset citation used by the dissertation: Cook, D.J. (2025) *CASAS Smart Home dataset - scripted activities, with and without activity errors*. Zenodo. https://doi.org/10.5281/zenodo.15712834

The repository provides download instructions rather than redistributing the original participant CSV files. The files under `evidence/event_logs/` are derived event-log snapshots generated by this project.

The Zenodo dataset is distributed under the Creative Commons Attribution 4.0 International licence (CC BY 4.0).

The released no-error archive contains 24 participant IDs even though the Zenodo description refers to 20 participants in each dataset. The analysis follows the inventory of the files actually provided: 120 no-error files and 100 scripted error files. Each CSV must contain `date`, `time`, `sensor` and `message`. Do not rename or edit the files.

## AD1 channel mapping decision

The textual Zenodo description and the supplied cabinet diagram use conflicting AD1 labels. The text lists AD1-A and AD1-B as water channels and AD1-C as the burner, whereas `Chinook_Cabinet.png` labels AD1-A as the burner and AD1-B/C as hot and cold water. The formal configuration uses AD1-A for the burner and AD1-B/C for water because this agrees with the labelled diagram and with the observed channel behaviour in the released task files. This is a documented researcher mapping decision rather than an unqualified dataset fact.
