# Software

This directory contains the Python implementation used to generate the event logs and evaluate the three case-level methods reported in the dissertation.

## Entry point and configuration

- `sensor2disco.py` — command-line entry point for generating the event logs and running the documented analysis commands.
- `requirements.txt` — Python dependencies required to run the software.
- `config/` — dataset mappings, file locations and fixed method parameters.

## Event log generation package

The main event log generation code is located under `sensor2disco/`.

- `config.py` — loads and validates the configuration files.
- `ingestion.py` — reads and validates the CASAS participant CSV files.
- `mapping.py` — maps low-level sensor records to readable activities.
- `quality.py` — performs data quality and consistency checks.
- `repository_room_abstraction.py` — constructs the Room/Action and Room Path event logs.
- `submission_pipeline.py` — coordinates data loading, event log generation and output writing.

## Evaluation package

The case-level evaluation code is located under `sensor2disco/experiments/`.

- `protocol.py` — defines the participant-grouped five-fold evaluation protocol.
- `features.py` — constructs the case-level features used by the evaluation methods.
- `rule_based_detector.py` — implements the proposed task-specific rule-based detector.
- `rule_based_evaluation.py` — evaluates the proposed method using the shared five-fold protocol.
- `cook_skipped_step.py` — implements the adapted Cook-based skipped-step detector.
- `reis_isolation_forest.py` — implements the adapted Isolation Forest baseline.
- `reis_evaluation.py` — evaluates the Isolation Forest baseline using the shared folds.

The `__init__.py` files identify the directories as Python packages and are not separate analysis modules.

Generated outputs are written under `outputs/` and can be regenerated by following the reproduction instructions.

For complete installation, data preparation and reproduction instructions, see [../REPRODUCE.md](../REPRODUCE.md).
